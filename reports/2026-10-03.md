# Cloudflare 新发布观察 · 2026-10-03

这期观察关注四个会改变应用选择的问题：故障发生在哪一段、agent 中断后由谁继续、证据来自自己的集合还是互联网、本机 demo 怎样只给指定的人看。公告集中于 10 月 2 日，本篇在 10 月 3 日收录；公告日、编辑日与费用生效日分别表达，不把同日日期当作覆盖全部更新的保证。

<!-- chapter: changes -->

## 01 / 先看改变了哪项判断

| 变化 | 原来需要单独拼接的环节 | 现在多出的选择 | 当前解释 |
|---|---|---|---|
| Observability / Traces / SQL | 平台与应用记录分散调查 | 按请求定位、定向采样与统一查询入口 | [观测与调查](../services/observability.md) |
| PiHarness | 自己接续 harness 与 DO 生命周期 | 由 Lifecycle 承接 Pi 的持久工作 | [Agent 运行](../services/agent-runtime.md) |
| Web Search API | 分别接 provider 的互联网搜索 | 经 Gateway 选择 provider | [检索与材料](../services/search.md) |
| Protected Quick Tunnel | 临时分享也要安排身份入口 | 短期 URL 加可选邮箱 PIN | [临时分享](../use-cases/temporary-sharing.md) |

本表是编辑判断。手册与主题页已经吸收这批解释；本篇保留这一批变化的时间位置，不要求读者从多份补记拼出当前做法。

<!-- chapter: observability -->

## 02 / 从留下日志，到沿请求调查

Traces open beta 把支持的规则、缓存、路由、Worker 与源站处理放进请求时间线；Trace Rules 可单独提高调查流量的采样。SQL API beta 为多种 dataset 提供共同入口，当前仍是每条 statement 一个 dataset。统一接口降低调查接入成本，应用内部的阶段记录和因果验证仍要自己完成。[S98] [S99] [S103]

实际选择可以先从一个慢请求开始，保留请求身份与版本，比较正常请求，再决定需不需要接 MCP 或外部 OTLP backend。本文没有进行生产调查实验；完整条件见[当前主题](../services/observability.md)。

<!-- chapter: agents -->

## 03 / Harness 状态与 Linux 环境分开成长

PiHarness 为 beta，Pi Durable 为 experimental。Pi 的持久 loop 与 inbox 接入 DO SQLite，Lifecycle 承接重新唤醒；这给第三方 harness 增加了具体云端路线，并不替代 Sandbox 工具环境或既有任务系统。[S104] [S105]

官方 `replay: "safe"` 示例是字数计算。对不可逆动作，继续检查外部幂等与结果查询；不能把工作可恢复读成副作用可任意重放。当前解释已进入[手册工作空间章](../guides/handbook.md#workspace)，Clef/Jev 的模型比较不因这条 harness 新闻而变成错误资料。

<!-- chapter: retrieval -->

## 04 / 搜索入口统一，证据来源仍有区别

Web Search API beta 经 AI Gateway 搜当前互联网；AI Search 仍面向交给它的集合。应用可从一个 facade 选择 provider，但先读回来源，才能知道摘要有没有漏掉日期和适用条件。[S106]

Provider 表当前将 Exa ZDR 标为 No，而公告称三者均支持；具体差异、费用与响应形式集中在[检索主题](../services/search.md)。没有 provider benchmark，也没有把价格排名当效果排名。[S107]

<!-- chapter: sharing -->

## 05 / 短期分享不用先变成长服务

Protected Quick Tunnel 可用 `--allowed-mail` 要求指定邮箱 PIN，停止连接器后访问结束。这适合短期 demo；不加限制的 Quick Tunnel 仍向持有 URL 的人开放。[S109]

既有本机服务可以先分享，之后再决定长期域名、Access 和运行位置。电脑关机后仍需可读，则要把交付放到持续运行的一侧。检查路径见[临时分享](../use-cases/temporary-sharing.md)。

<!-- chapter: economics -->

## 06 / 十二月计费，今天先记录迁移条件

**统一 Observability 计费自 2026-12-01 起适用；本期日期仍是 2026-10-03。** Paid 公布 50 GB 摄取与 12 GB-month 保存包含量，超出为 $0.25 / GB 与 $0.10 / GB-month；Enterprise 在续约时迁移。未采样安全 dataset 不使用这份共享包含量。[S100]

发布博客写 10 GB-month，当前 pricing docs 写 12，本篇采用文档并保留差异。完整的“当前适用 / 已公布”对照由[手册费用章](../guides/handbook.md#economics)提供。AI Search 的 11 月 1 日起算继续按原来源阅读，旧期观察没有被自动重写。[S10]

## 07 / 什么可以现在读，什么还要实验

四组能力已进入主题正文与阅读入口；采用哪条路线取决于自己的需求。官方查阅支持能力介绍，不能替账户开放、真实邮箱、模型质量或生产恢复验收。

值得另行明确目标再实验的，是一条实际慢请求调查、一次 PiHarness 的中断恢复、相同问题的 provider 比较，以及允许/拒绝邮箱与停止连接器。这里没有运行它们，也不自动创建资源或花费。

对旧 PDF 读者，使用[出版物入口](https://indeliblevivi.github.io/cf-fieldbook/publications.html)按作品找到当前阅读与版次更新。新的观察单独形成出版候选，手册与专题按各自内容变化修订，不随每条新品陪跑升版。
