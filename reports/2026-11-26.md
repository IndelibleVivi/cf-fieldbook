# Cloudflare 新发布观察 · 2026-11-26

这次接着 11 月 6 日的观察，筛查官方 changelog 与博客中 **11 月 6–25 日**的变化，查阅截止 11 月 26 日。最值得先核对的三件事是公开检索会收进哪些内容、旧部署还有没有可访问的地址，以及 12 月 1 日起哪些费用改变。实践条件已接回[当前手册](../guides/handbook.md)，本篇保留此次查阅的时间范围。

<!-- chapter: public-search -->

## 01 / 给公开站点一个可发现的搜索入口

11 月 25 日推出的 **Search for Agents** 在各计划开放 beta。对已接入 Cloudflare 的域名启用后，平台在 `default` namespace 创建 AI Search 实例，并提供 `/.well-known/search`。HTML 可宣告入口，开启 Markdown for Agents 后 Markdown 响应也带发现信息。查询用 GET 的 `q` 或 HTTP QUERY 请求体，返回带来源的 Markdown 片段，供调用方自行组织答案。[S230] [S231]

默认沿 sitemap 和站内链接发现页面，使用 hybrid search、24 小时同步与 48 小时相似查询缓存，默认不含子域。启用前先核对可被索引的内容，等待索引完成后拿真实问题验收来源链接和撤下时效。请求仍受网站的 AI Crawl Control 与 WAF 配置影响，摄取、存储与查询走 AI Search 自身的额度与费用。对此类公开端点，应只索引预期公开的内容；私有资料继续由应用按用户约束检索。[S230] [S231] [S10]

<!-- chapter: search-sources -->

## 02 / D1 的一行可以成为一份检索文档

11 月 12 日的 D1 数据源 beta，按一条只读查询把每行索引成独立文档。查询需要非空、唯一、类型一致的 `id`，最多返回 100,000 行，分页顺序由服务按 ID 决定。REST／binding 配置须用同账户数据库及具备索引读取权限的 service API token ID。稳定行 ID 有助于同步识别同一文档，应用仍需核对输出列和索引的读取边界。[S232] [S233]

11 月 17 日新增可选文件摘要。对至少切成三块的文本文件，索引可生成摘要、关键词及主题，既有 `context` 会保留。默认关闭，开关变化会触发全量重建；更新时 `indexing_options` 整体替换，原设定的 tokenizer 等需要一并带回。摘要调用走 Workers AI 与实例的 AI Gateway（未配置则走 `default`），独立于 AI Search 摄取包含量。开工前先数文件和重建范围，再决定是否为这层模型调用付费。[S234] [S10]

<!-- chapter: extraction-prices -->

## 03 / 原 Clairic 选择器换了模型，12 月起也换单价

11 月 18 日，Cloudflare 公布更新的 Clairic 和 Clairic-flash，并发布两者权重。原 `@cf/cloudflare/clairic` 选择器原位更新为 27B 模型，较轻的 9B 路线现在有独立的 `@cf/cloudflare/clairic-flash`。字段 API 仍保留 typed values、confidence 与原文位置，旧调用方即使没有改代码，也值得用自己的固定样本重跑。[S235] [S164] [S236]

| 托管模型 | 11 月 26 日公布输入价／M tokens | 自 12 月 1 日起 |
|---|---:|---:|
| Clairic | $0.10（优惠） | $0.24 |
| Clairic-flash | $0.10 | $0.10 |

两者无输出 token 费。模型卡均列 65,536 tokens，目前明示每个 pass 重计完整 `state` 与图片；旧版模型卡的 8,192-token pass 字样本次已找不到。图片、字段与文字共享预算，`state` 仍可能截断，成本以 `usage.input_tokens` 与 `usage.passes` 核对。发布博客描述最高四张图片或 PDF 页的文档场景，接入时仍以所用端点的实际输入 schema 为准。公开 benchmark 属供应商自测，本书没有执行推理或比较准确率。[S235] [S164] [S236] [S237]

<!-- chapter: durable-wait -->

## 04 / Pi 1.6 把等待交还给可休眠的对象

Agents SDK **0.34.0** 接入 Pi 1.6。工具可返回 `ToolPark` 等信号或期限，等待期间不占 invocation，DO 可以 hibernate；收到 `harness.signal()` 或期限到达时，Pi **再次运行该工具**。审批可在 `beforeTool` 先挂起，父会话也可用 `notify` 等子会话 settle。将提问、发送通知或写入等动作绑到稳定身份，醒来先检查已有结果，尤其要区别重复投递和新输入。[S238]

会话可用 `init` 一次写入已有 transcript，`submit(..., { onAbort: "keep" })` 能保留排队输入。已经在 1.6 上运行的会话，Pi 1.5 无法继续它的 tool calls 或 model requests；升级前想清楚旧会话怎样接续，部署故障应向前修。MCP 重新授权或重连和通用 500／WebSocket 1011 的错误边界也有变化，见[运行时说明](../services/agent-runtime.md#pi-16工具挂起与唤醒)。[S238]

<!-- chapter: workflow-and-do -->

## 05 / Workflow 并发与 DO 断线各有自己的恢复条件

每条 Workflow 可通过 binding 的 `concurrency.limit` 限制并行实例数，不能超过账户上限。降低上限不会停止正在跑的实例，下一次部署省略配置会移除该限制。用它保护共享数据库或外部 API 时，还要保留原有期限、幂等与积压检查。[S239]

11 月 19 日，DO runtime 更新时重启的机器会更早从存储组退出，可降低 SQLite-backed DO 的重置频率，实际效果取决于负载。客户端仍要在 WebSocket 关闭后重连并补齐状态；此项改进与代码延迟更新、stub 自动重试以及 Pi 挂起分属不同层。[S240]

<!-- chapter: deployment-evidence -->

## 06 / 30 天以后，旧版本链接可能失效

Workers versions 和 Pages deployments 的保留期是 **30 天**，各自最近 **100** 个和当前部署继续保留。被清理的 Worker Version URL（含 alias）和 Pages 单次部署 URL 会失效；Worker 可部署或回滚的范围仍是最近 100 个版本，Pages 则只能回滚至尚在保留的 production 部署。Workers Builds 的 **90 天**对应构建记录与日志，读发布证据时要分开看。[S241] [S242] [S243] [S223]

分支／PR 可以使用 Worker Previews；Preview URL 指向该 Preview 的最新部署，旧式 Worker Version URL 使用生产 bindings。11 月 23 日 Preview 开始支持 CPU／heap profiling，也可按 ID 对 Preview 自己的 DO 取样。比较变更前后时记录具体 deployment ID、测试输入和结果。要长期回看某次结果，可另存 commit、构建产物和验收记录。[S241] [S244]

<!-- chapter: spending-controls -->

## 07 / 支出限制会暂停操作，开通订阅也成为工具动作

Workers、DO 现在分别支持账户级 spend limits，按当前订阅周期记用量。邮件告警可让应用继续运行；开启阻断后达到阈值会暂停对应产品受支持的操作。暂停可能波及同账户多个应用，计量与阻断延迟也会使费用越过阈值。Workers Paid 基础订阅费、DO 存储费和别的产品都有各自口径。先确认可接受的停机范围，再决定告警或阻断。[S245] [S246]

`cf` 11 月 17 日进入 1.0 RC，Build Output 改用 `.cloudflare/output/v1/`。11 月 25 日公告的订阅激活另需 **rc.5+** 和重新认证取得 OAuth scopes，账户还须有已核验邮箱、付费资料和支付方式。支持 **MCP 2026-07-28** 及 elicitation 的客户端可展示价格并请求确认。不支持 elicitation 时由 Dashboard 接续。工具授权能打开入口，是否订阅仍由账户所有者决定。[S247] [S248]

<!-- chapter: december-billing -->

## 08 / 12 月 1 日前，按服务重算账本

- **AI Search** 公开价页仍写 **12 月 1 日**起算。查询与摄取公布单价和包含量未变；另算文件摘要、生成、查询改写或外部模型的费用。[S10] [S204] [S234]
- **Observability** 公开计划仍于 **12 月 1 日**切换自助账户计量。先区分摄取与保留量，按[观测费用表](../services/observability.md#费用当前适用与将来生效)核对；现价页以均匀摄取 75 GB、保留 7 天估算 17.5 GB-month，合计 **$7.00**。旧观察的 20 GB-month 假设仍会算得 $7.25。实际存储量按每天可查询 GB 的峰值求和再除以 30，月末摄取的数据可能计入下一周期。[S100] [S111]
- **Artifacts** 现价页现在写 **11 月 19 日**开始计 operations 和 storage，历史还出现 10 月 14／15 日、11 月 12 日。按现价做预算，保留历史实际起算未知。仓库数量费另列为待生效，未给日期。[S07] [S08] [S135]

同一天还有一项不同性质的变化：Workers 的 `Temporal` 在 **compatibility date ≥ 2026-12-01** 时默认启用，早期日期可开 `temporal`，需要保留旧行为可用 `no_temporal`。日历到了 12 月 1 日，不会替现有 Worker 改 compatibility date。[S249]

<!-- chapter: local-testing -->

## 09 / 本地模拟能验证到哪一步

Artifacts 现在可在 Wrangler、Vite 或 Vitest 本地开发中使用分开的 repo 模拟器；选择 `remote = true` 会切回已部署的 repo。外部 HTTPS import 是另一条需要网络的操作。Browser Run 的 `.quickAction()` 在 Wrangler dev 下可用本机 Chrome，`json` 只用 schema 合成占位结果，本地模式也还不支持 Kitesurf。在本地检查绑定、输入和响应形状之后，仍须为真实网络、模型和账号行为取得独立证据。[S250] [S251]

已有资料架也复看了 Static Assets 前缀：11 月 11 日公告确认 Wrangler 的 `assets.base_path` 与 cf 的 `worker.assets.basePath`，继续用根路径的例子可按[原发布路线](../use-cases/publish-reading-shelf.md)运行。发布前后仍要读回实际页面与原文下载。[S222] [S252]
