02 / 更新与撤下笔记

更新：准备新原件和派生内容，检查后才切换当前版本。旧引用可以保留版本身份。

撤下：先停止对读者返回该文档，再处理搜索索引与缓存。物理删除是另外一个动作。

练习：将这份文档的某一句改写，重新生成资料架并检查页面与下载一致。离线例子没有权限或在线索引，不能证明远端缓存已清除。

03 / 阅读检查单

1. 三份文档都能打开，下载仍是原 Markdown。 2. 问“哪份讲撤下”能回到第二份原文。 3. 问“资料架里没有的论文结论”时，应明确材料不足。 4. 改动第二份后重新生成，页面和下载使用相同版本。 5. 即使 JavaScript 被关闭，阅读与下载仍然可用。

扩展为私有系统时，再检查匿名访问、过期身份、已撤下内容和旧版本引用；这些检查不属于当前公开静态例子的能力。
